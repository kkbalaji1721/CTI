# Lab 16.1 – Same Dataset in MongoDB, Cassandra and Neo4j

University enrollment data modelled in three databases.

- `mongodb.js`, `cassandra.cql`, `neo4j.cypher` – schemas and queries
- `run_lab16_1.py` – loads data, runs the 3 queries on each DB and times them
- `activity_16_1_hybrid.py` – hybrid architecture activity
- `COMPARISON.md` – comparison write-up

**Run:** from the project root, `docker compose up --build`.
