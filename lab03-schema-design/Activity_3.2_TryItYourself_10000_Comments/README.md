# Activity 3.2 – Try It Yourself: Post with 10,000 Comments

Shows why embedding every comment is a bad idea for a viral post (16 MB document limit, growing writes) and demonstrates the bucket/reference alternative.

- `lab_3_2_try_10000_comments.py` – solution script
- `viral_post.json`, `comment_buckets_sample.json`, `viral_comments_sample.json` – sample outputs

**Run:** `python lab_3_2_try_10000_comments.py`
