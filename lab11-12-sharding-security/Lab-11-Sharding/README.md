# Lab 11 – Sharding

Two-shard cluster (Docker Compose) for shard-key experiments.

- `LAB11_1_DECISION_MATRIX.md` – shard-key decision matrix (Lab 11.1)
- `scripts/lab11_1_resharding.js` – optional resharding demo
- `scripts/prepare_lab11_2.js`, `scripts/verify_lab11_2.js` – hotspot vs hashed key experiment (Lab 11.2)
- `python/insert_data.py` – data loader

See the [parent README](../README.md) for prerequisites and the Docker image build step.
